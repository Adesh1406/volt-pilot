# ⚡ VOLT PILOT – AI Power Manager

VOLT PILOT is an intelligent power-management system designed to monitor and manage energy generated from solar power and stored in a battery.

## 🚀 Project Overview

The system continuously monitors:

- ☀️ Solar power generation
- 🔋 Battery voltage and current
- ⚡ Load power consumption
- 📊 Real-time energy parameters

An ESP32-S3 acts as the main controller and processes the sensor data.
